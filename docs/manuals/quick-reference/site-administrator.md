# Quick Reference: Site Administrator

**Scope:** one website · **Full manual:** [CMS Administrator Manual](../cms-administrator-manual.md)

## Users (your site)

| Task | Where |
|---|---|
| Give an existing TMC account a role on your site | *Users → Add New → Add Existing User* → role → **Add Existing User** |
| New account | Request from TMC IT (Super Admin) with the unit head's written approval |
| Change a role | *Users → All Users → Edit → Role* |
| Remove someone (transfer/exit) — **same day** | *Users → All Users* → hover → **Remove** |

Roles: **Content Editor** (drafts, submit) · **Reviewer / Publisher** (approve, publish, schedule) ·
**Site Administrator** (settings, menus, users of this site). Give the lowest role that works.

## Site settings

| Setting | Where |
|---|---|
| Address, phone, e-mail, social links | *Appearance → Customize → TMC contact details* |
| Hindi address | *Languages → Translations* → group "TMC contact details" |
| Menus (Main menu, Footer quick links, Footer policies — one set per language) | *Appearance → Menus* |
| Site title, tagline | *Settings → General* |

**Do not change:** time zone, date format, permalinks (links would break).

## Menus in 4 steps

*Appearance → Menus* → pick the menu of the language → add pages/listings from the left, drag to order
(drag right = sub-item), short **Description** for top-level items → **Save Menu** → repeat for the other
language.

## Every quarter

Review *Users → All Users*: confirm the list to TMC IT; remove accounts no longer needed.

## Need something the CMS cannot do?

New template, field, content type or design change = **Change Request** to TMC IT (never ask for a manual
server change).
