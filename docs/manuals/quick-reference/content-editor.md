# Quick Reference: Content Editor

**Sign in:** `https://<your website>/wp-login.php` · **Help:** your Site Administrator, or a *Support
incident* ticket · **Full manual:** [Content Editor Manual](../content-editor-manual.md)

## You can / you cannot

| You can | You cannot |
|---|---|
| Create and edit drafts of pages, news, notices, tenders, events, job openings, departments, doctors | Publish or schedule |
| Upload images and documents | Change anything already published |
| Submit for review; see status in **My submissions** | Change colours, fonts, menus, settings |

## Create content in 6 steps

1. Left menu → the type (*Pages*, *Posts*, *Tenders & EOIs*, *Events*, *Careers*, *Departments*,
   *Doctors*) → **Add New**.
2. **Title**, then the text. Use **Heading 2 / Heading 3** in order; lists for steps.
3. Fill the **Details** box (required fields marked \*). Yellow **Details missing** = something required
   is empty.
4. Pages: choose the **Parent** page. Posts: choose the **Category** (News / Notices).
5. **Save draft** → **Preview**.
6. **Submit for Review**.

## Dates that act automatically (IST)

| Field | Effect |
|---|---|
| Tender: *Last date and time of submission* | Tender moves to the archive |
| Job: *Last date to apply* | Opening moves to the archive |
| Notice/news: *Expires on* | Leaves the notice board and lists |
| Event: *Starts* | Event becomes "past" after that day |

## Hindi version

Save the English item → sidebar **Languages** → **+** next to **हिन्दी** → enter the TMC-supplied Hindi
text, fill Details, choose the Hindi parent/category → **Submit for Review**.

## Returned for changes?

Dashboard → **My submissions** shows the **reviewer's note**. Make the changes → **Submit for Review**
again.

## Always

- Alternative text for every informative image.
- PDFs with real text (not scans), clear file names.
- Link text that says where it goes — never "click here".
- No patient-identifiable information. Only TMC-approved content.
