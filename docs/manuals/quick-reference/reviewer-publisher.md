# Quick Reference: Reviewer / Publisher

**Sign in:** `https://<your website>/wp-login.php` + authenticator code (W2) · **Full manual:**
[Content Editor Manual §11](../content-editor-manual.md#11-review-approval-and-scheduling)

## Your queue

Dashboard → **Awaiting your review** (oldest first) or the top bar → **Review queue (n)**. You are also
e-mailed when an item is submitted.

## Review checklist

- [ ] Approved by the content owner; facts, dates, reference numbers correct
- [ ] No **Details missing** warning
- [ ] Right parent page / category / language; Hindi version linked where supplied
- [ ] Headings in order; meaningful link text; alternative text on images
- [ ] Documents open and are the right versions
- [ ] No personal or patient-identifiable information

## Decide

| Decision | Steps |
|---|---|
| **Return** | Write in **Review note** → **Save** → status *Pending Review* → **Draft** → **Save**. Author is notified. |
| **Publish now** | **Publish** |
| **Schedule** | Publish panel → click "Immediately" → date and time (IST) → **Schedule**. Goes live automatically (checked every minute). |
| **Correct a live page** | Edit → **Update** (live at once; recorded in the audit trail) |

## Automatic — no action needed

Tenders and job openings close, notices expire and events become past at the dates in their Details.
To extend, change the date to a future one.

## Undo a mistake

Open the item → **Revisions** → compare → **Restore This Revision**. Nothing is lost.

## Your responsibility

Once you publish, the content is public on a Government of India website under TMC's name. When in doubt,
return it with a note.
